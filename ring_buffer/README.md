# Ring Buffer (C++)

This is a small project to learn more about low level C++ and ring buffers.
This was inspired by this [article](https://rigtorp.se/ringbuffer/)


## Usage

Compile:

```bash
$ g++ -Wall -O3 -march=native -std=c++20 ring_buffer.cpp -o ring_buffer_test
	
```

Run with:
```bash
$ ./ring_buffer_test [buffer_size] [iterations]	
```
